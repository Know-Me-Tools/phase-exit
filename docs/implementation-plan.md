# Approved first-uar-example plan

Approved by the operator on 2026-10-16. Deliver a Rust CLI and reusable engine,
Node24.22.0/TypeScript7.0.2 hooks and native harness packages, two Agent Skills,
append-only evidence/learning/amendments, and the existing UAR phase as the first
real example. Pin jev-1.14.0 preview. Public Know-Me-Tools/phase-exit, Apache-2.0.

Core: strict versioned contracts with sourced stable criteria, stage dependencies,
approved actions, complete implementation boundary, adopted revisions and exact
artifact identity. COMPLETE, CONTINUE, WAIT, BLOCKED, REVIEW_REQUIRED and INVALID
have distinct behavior. Stage completion is never phase completion. Missing/stale
proof only authorizes an already approved gate at its boundary. Runtime receipts,
not model prose, establish production facts. No requirement/test generation.

JEV: System One HTTPS API, process-environment key only, exact preview response
model, strict typed probabilities and question IDs, redacted minimal packets,
no truncation, bounded transient retries, content-addressed cache, no repeated
semantic sampling. Semantic support >=.95 and contradiction <=.05 are required;
confident contradiction and uncertainty remain separate. No inference can waive
missing deterministic evidence or unavailable external collaborators.

Lifecycle: draft/reviewed/adopted immutable contracts; explicit operator revision
adoption and invalidation maps; append-only discoveries, preserved failed receipts
and supersession. Hooks cannot rewrite mandatory predicates or create scope.

Packages: canonical phase-contract and phase-exit skills; Claude2.1.301 and
Codex0.163.0 native repo marketplaces; OpenCode2.0.31 V2; Kimi2.2.0 current plugin
and catalog; DeepSeek0.2.0-rc.2 Cordis bundle. Package identity and actual exercised
capability are separate. Host hook transport limits are disclosed. Native Windows
qualification, older harnesses, public-directory approvals, MCP server and MCP app
are excluded. Write two follow-up issue drafts, not new first-pass gates.

Execution: lead coordination/docs/fixtures/UAR importer; one Rust author and one
TypeScript author, then isolated artifact review. Entire implementation inventory
precedes any check. Run one serialized bounded CLI/filesystem/JEV/Node/current-host
program. Test real boundaries, with deterministic failure transport fixtures only
for errors impractical to cause externally. No broad benchmark or unrelated tests.
One initial + one corrective artifact review maximum; unresolved critical finding
stops for an operator decision, never becomes a pass when a cap is reached.

UAR: preserve active run and original receipts. Adopt explicit mapping of the
19-item/17-count and six-group/obsolete-seven discrepancies without overwriting
history. Read existing evidence; do not execute/import its Python runner here.
After original run ends, repair complete failure cohort, renew full inventory,
rerun only affected gates. V2 pass precedes tag/image publication; both published
child programs precede verified release; issue/readback/reflection close phase.
Missing qualified supervisor remains an external blocker, not a fake pass. No
know-me mutation, cancelled-program revival or immutable-tag movement.

The uncomfortable limit: schema correctness, hashes and JEV confidence do not
prove absence of all bugs or prevent privileged local bypass. Preserve honest
blocked outcomes and enforcement coverage instead of asserting universal control.
