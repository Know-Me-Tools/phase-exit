# Establishing and revising authority

1. Read authoritative assessment, analysis, specification and plan records.
   Preserve exact bytes and hashes; reference original artifacts rather than
   replacing inconvenient history. Resolve contradictory requirements explicitly.
2. Build the draft from the current schema. Reject duplicate IDs, missing source
   references, cycles, empty acceptance definitions and unresolved contradictions.
   Derive counts from the inventory. Identify the complete implementation boundary.
3. Review the frozen artifact with an independent reviewer who receives artifacts
   only. Distinguish source inspection from runtime verification. Respect the
   adopted review cap; exhausting it is not a pass.
4. Show the contract summary, exclusions, external prerequisites, allowed actions,
   model/thresholds and required hooks. Record the operator's explicit adoption.
   Existing authorization can cover initial adoption when the approved scope is
   concrete; it never authorizes a newly invented requirement.
5. Import original receipts with runner, command, terminal result, source, fixture,
   platform, configuration and artifact identities. Do not execute evidence files.

On discovery, append evidence references and affected criterion IDs. Classify it
as clarification, in-scope observed defect, proposed new scope, external dependency
or deferred improvement, and record its disposition. A repair is authorized only
when an existing criterion and observed evidence support it.

For amendments, compare immutable revisions, explain why each criterion changed,
and invalidate affected evidence including dependent criteria. Unknown impact
requires review. Changed semantics, required evidence, model, threshold or mandatory
hooks require adoption. Do not tune confidence thresholds to obtain a desired pass.

When working on UAR, import the six approved image groups and four exact source
supplements. Reconcile historical inventory counts and seven-group wording in an
adoption mapping. Preserve original artifacts. Missing genuine supervisor
qualification remains an external blocker; production availability is not proof.
